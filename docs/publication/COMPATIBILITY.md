# Compatibility

## Blender

Blender **5.2.2 LTS** has been used for source registration and package checks. This evidence does not constitute visual UI acceptance at every display scale or validation of every modeling operation. The extension manifest minimum is a packaging requirement, not a broad compatibility claim.

## MCP clients and transports

Client/transport support is claimed only when tool discovery and invocation have been verified end to end and recorded. This publication draft makes no unverified client compatibility claims. Check the release-specific verification record before enabling a client.
